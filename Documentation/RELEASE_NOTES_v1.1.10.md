# Release v1.1.10

Canonical frozen reproducibility release for the revised iScience manuscript.

## Included

- standalone R pipeline v1.1.10
- publication-facing main and supplementary outputs
- figure source data
- sensitivity analyses and audit outputs
- R session information
- source-data access specifications
- file manifest and SHA-256 checksums

## Public-release hygiene

Original third-party source data are not included. Two internal high-BMI source-row audit artifacts that most closely resembled direct source excerpts were deliberately omitted from the public repository; the public supplementary summary and validation outputs remain available.

## Analytical status

The v1.1.10 release is a reporting-and-packaging refinement of the validated analytical foundation. It does not intentionally alter the input data, model specifications, formulas, random seeds, or numerical results.
