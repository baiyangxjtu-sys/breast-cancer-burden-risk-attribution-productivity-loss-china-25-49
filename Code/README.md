# Analysis code

This directory contains the complete standalone R analysis pipeline used to reproduce the analyses reported in the revised manuscript.

- Frozen analysis release: **v1.1.10**
- Primary analytical script: `GBD_EOBC_full_pipeline_FINAL_STANDALONE_v1.1.10.R`
- R2 presentation patch: `GBD_EOBC_full_pipeline_FINAL_STANDALONE_v1.1.10_R2_FIGURE_PATCH_FINAL.R`

The R2 patch implements second-round presentation and labeling updates only. It does not change the frozen analytical calculations or numerical results.

Original third-party input data are not included. See `../Source_Data_Access/` for source descriptions and expected input-file specifications.
